# Sentinella

App Android per tenere d'occhio dispositivi e siti, in stile Uptime Kuma.

- Controlli **Ping** e **HTTP(S)** fatti direttamente dal telefono
- Elenco con percentuale di uptime (24 h) e barra dei controlli
- Dettaglio con grafico dei tempi di risposta, uptime 24 h / 30 giorni, scadenza certificato ed eventi
- Avvisi quando un monitor va offline o torna online
- Controllo continuo a schermo spento (notifica fissa), altrimenti circa ogni 15 minuti

L'APK viene compilato da GitHub Actions a ogni modifica e pubblicato nelle **Release**.
